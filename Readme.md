The experiment

Can I prepare for and pass the SnowPro Core (COF-C03) certification using only Claude for learning — no courses, no books, no videos?

Rules

Allowed

Claude: concept notes, labs, exam-style questions, review sets, mock exams
My Snowflake trial account, for running the labs Claude gives me
Official Snowflake doc pages, only when Claude links one for a feature that may have changed recently
Outside practice questions, for testing only (not as study material)

Not allowed

Courses (Coursera, Udemy, DataCamp, Snowflake University)
Books, videos, blogs, study guides
Method

For each topic:

Concept notes: defaults, limits, edition differences, roles/privileges, credit costs, exam traps
Hands-on lab in the trial account (SQL saved in this repo)
8–10 exam-style questions, answered one at a time
"Must remember" list

Plus a 20-question mixed review after every 3 topics, and 100-question mock exams scored by domain.
